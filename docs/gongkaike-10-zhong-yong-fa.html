公开课神器“堂测”：10 种用法，拿去就能试

堂测小编 · 2026-11-18 · 堂测网

《公开课神器“堂测”快速使用指南》那篇只讲了堂测发卡、建题、扫码三步。如果已经会用这三步，还想继续丰富公开课互动，就可以看看下面这些用法。这篇把指南里没展开的 10 种用法单独拿出来，每一种都配一个能直接搬进课堂的例子。

1. 出门票

下课前留两分钟，扫一道跟本节目标直接相关的题。全班答完，数据提交后，在 Web 端看到各选项比例，这节课有没有达标，老师当场有数，不用等到作业交上来才发现。

2. 课前摸底

新课开始先扫一道，扫完提交后看 Web 端各选项比例，看看学生已经会多少。比如讲分数加法之前，先测一道同分母加法，全对就少讲概念、多讲应用；一半人错，就从概念重新讲。

3. 两轮测

同一道题测两次，中间加一段讨论。第一轮先在 Web 端看各选项比例、先不公布答案，让学生知道“班里有一半人跟我想的不一样”；讨论完再扫码测一轮，提交后看结果，和第一轮对照，看看想法变了没有。公开课上这一轮讨论，往往是整节课最出彩的几分钟。

4. 选项投票

选下节课的探究主题、选小组展示的顺序、选读哪篇文章，都可以举卡投票。老师在 Web 端看各选项比例和选各选项的学生名单，表决结果当场就能看到。

5. 小组竞赛

把全班分成几组，同一道题各组派代表举卡，或者全组举卡。老师按 Web 端各选项比例和名单给各组记分，答对加分、答错不扣分，竞赛的劲头一上来，平时不举手的学生也可能跟着举卡。

6. 情绪打卡

开课先扫一道“你今天感觉怎么样”，按单选设置，状态选项不超过 4 个。提交数据后，老师在 Web 端查看选择各状态的学生名单，谁今天状态不对，课后单独找这位学生聊两句。这道题不计分，只作了解学生用。

7. 学生出题

复习课上让学生自己出一道题，注明正确答案和干扰项，老师录入 Web 端题库后，第二天用堂测全班测一遍（按单选题设置，选项总数不超过 4 个）。出题的学生要先把知识点吃透，答题的学生往往也更认真，因为题是同学出的。

8. 按错题分组再教

用堂测测完一看，比如错 A 的十个人、错 B 的八个人，选错的选项不一样，分组也不一样。下节课直接按选错的选项分组，每组练自己的薄弱点，比全班重讲一遍省时间。

9. 副科快测

体育、音乐课结尾时间紧，快速扫一道：让学生用选项自评本节表现，或者测一个本节知识点。选项按单选设置、不超过 4 个。工具要让路，不占用下课时间。

10. 大班分批扫

合唱团、年级大课人数多，答题卡是 1–128 号，一次扫不完可以试着分两批扫。人数多不是不能用，只是扫的时候分两步走。

这 10 种堂测用法，有的适合课前或课后快速使用，有的适合嵌入课堂讨论和反馈环节。不用一次全上，挑最贴近你下节课的那一种，先试一次。
