分层作业不用每道题都分，先分这 3 类

堂测小编 · 2026-11-18 · 堂测网

分层作业卡住时，先别急着把学生分成基础组、提高组。

真正难的是，一道题一道题判断难度，再给不同学生准备不同版本。备一节课的时间都花在贴标签上，第二天还有新课要上。

统一布置也不合适。基础弱的学生卡在后半页，写不动就空着；学有余力的学生前半页刷完，剩下的时间闲着。

先把分类对象换过来：这里分的是题，不是学生。老师可以看这道题要求学生做什么，再决定它属于哪一类。学生根据自己的情况往上选，不给谁贴标签，也不规定谁只能做哪一类。

下面以八年级数学一次函数为例，只讲这三种分法。

第一类，照着做的题。

概念和公式直接套，步骤清楚，做完能对照答案或过程检查。这一类承担基础任务，全班都要完成。

一次函数里，画出 y=2x+1 的图象，就是现成的例子。先取点，再连线，最后标出图象经过的象限和与 y 轴的交点。步骤明确，学生照着画就能完成。

第二类，换着问的题。

条件换一个方向，或者把图象里的信息读出来再处理。题目不再是直接套步骤，学生要先把条件转换一下。

已知 x=0 和 x=1 时对应的 y 值，求函数表达式，就是这类题。学生要先读出两个点，再利用待定系数法求出表达式。

还可以给 y=(m-3)x+4，问 m 为何值时函数递增。先看一次函数的系数 k=m-3，再判断 k 大于 0 时函数递增，所以 m 大于 3。

这类题还可以叠几个条件：已知一次函数图象经过点（1，3），与 y 轴交于点（0，-1），求它与 x 轴的交点。

第三类，自己搭的题。

题目给出真实情境，学生自己列关系式，再完成判断和解释。没有现成步骤摆在那里等着套。

比如给出一段气温变化图，横轴表示连续时段，纵轴表示对应气温，让学生从图中选取一段连续下降的数据，说明 x 增大时 y 怎样变化，再联系一次函数的增减性。

学生要做的不是背一句“y 随 x 增大而减小”，而是读懂数据、写出关系，再解释自己的判断。

分完以后，布置时先把第一类设为全班必做。第二类、第三类作为选做，具体数量可以按本班情况调整。

学生能在完成第一类后继续尝试，就向上选；暂时做不动，不代表基础任务没有完成。

批改时也能顺着三类看：谁在第一类步骤上出错，谁到了第二类还没转过弯，谁在第三类不会列关系式。

讲评不必三类都统一讲。第一类的基础错误，全班一起过；第二类挑典型问题讲；第三类可以展示学生列出的关系式，再一起检查情境、变量和结论是否对应。

这三类的界线不是刻死的。同一道题换一种问法，可能从“照着做”变成“换着问”；情境信息更完整时，也可能需要学生自己搭关系。

老师可以先拿手头这一节的题过一遍，能归进去的就归，暂时归不进去的先放着，不用硬凑。

这套分法只拿八年级数学一次函数举例。换成其他章节，要重新看题目要求学生做什么，不能直接把一次函数的做法搬到所有学科。

老师明天可以先挑一道一次函数练习题，判断它是在照着做、换着问，还是需要自己搭关系。

八年级数学一次函数这一章，你给第二类题找变式的时候，卡住你的是条件不好改吗？
